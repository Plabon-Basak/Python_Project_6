# Python Project 6

A collection of three interactive Python console applications demonstrating Object-Oriented Programming concepts including classes, inheritance, and encapsulation.

## Projects

### 1. Bank Account Simulator
A console-based banking application that allows users to:
- Create new bank accounts with an initial deposit
- Deposit and withdraw funds
- View account details and balance

**Features:** Input validation, account management, transaction history

### 2. Library Management System
A digital library catalog system that enables users to:
- Add new books to the library
- View the complete book catalog
- Borrow and return books

**Features:** Book status tracking (Available/Borrowed), catalog browsing

### 3. Employee Management System
An employee database demonstrating inheritance with three employee types:
- **Employee** - Base class (10% bonus)
- **Manager** - Extended with department info (20% bonus)
- **Developer** - Extended with programming language (50% bonus)

**Features:** Polymorphism, method overriding, employee categorization
